# Python Assignment
## PyBank

In this task I simply calculated a net change between current and last months profits/losses in a loop.
Then I added this net change to the list, and also checked if this net change is the greatest increase or decrease from all the changes I had.
<br/>At the end of the loop it's important to put current profit/loss into the variable that holds last month profit/loss, so the loop works correctly.
<br/>For the output, I created the list of strings that are going to appear in the final analysis.
Then, in a for loop, I both print them in the terminal and write them in the analysis file.

## PyPoll
In this task I created an empty dictionary, where keys will be the candidates of this election and values will be their vote counts.
<br/>In the loop, I check if the candidate, that the current voter voted for, exists in my dictionary, and increment their vote count by one or add them in the dictionary with vote count equals to one.
<br/>When all votes are distributed between the candidates, I calculate the percentages of their votes and determine who is the winner of the election.
<br/>The output method is the same as in my PyBank task.
